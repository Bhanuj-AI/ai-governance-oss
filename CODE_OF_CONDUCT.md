# Code of Conduct

## Our Pledge

We are committed to making Kavach a welcoming, respectful, and productive open source community.

Kavach is about governance, trust, and careful engineering for AI systems. The project community should reflect those same values: clear communication, good-faith collaboration, and respect for the people doing the work.

## Expected Behavior

- Be respectful and considerate in discussion, review, and disagreement.
- Assume good intent while still being precise about technical concerns.
- Give actionable feedback that helps improve the project.
- Credit ideas, prior work, and contributors where appropriate.
- Keep discussions focused on the work, the users, and the project goals.
- Be mindful that AI governance work can involve sensitive organizational, operational, or safety concerns.

## Unacceptable Behavior

- Harassment, intimidation, threats, or personal attacks.
- Discriminatory language or behavior.
- Trolling, sustained disruption, or bad-faith argument.
- Publicly sharing private, confidential, or security-sensitive information.
- Sexualized language, imagery, or unwanted attention.
- Conduct that would reasonably make participation unsafe or unwelcome.

## Scope

This code of conduct applies in project spaces, including issues, pull requests, discussions, reviews, and other public or maintainer-recognized communication channels. It also applies when someone represents the project in public spaces.

## Enforcement

Maintainers may remove comments, close issues, reject contributions, or temporarily or permanently restrict participation when behavior violates this code of conduct.

Enforcement should be proportionate, consistent, and focused on protecting the health of the project and its contributors.

## Reporting

If you experience or observe unacceptable behavior, report it to the maintainers using the most appropriate private channel available for the project. If no private channel is available, open a public issue only with enough detail to request maintainer contact, and avoid sharing sensitive personal information.

## Attribution

This code of conduct is adapted from common open source community standards, including the Contributor Covenant, with wording tailored for Kavach.
